# Contribution Guidelines

## Issues Welcome

We welcome issues for discussion, questions, feedback, and suggestions. Please feel free to open an issue.

## Pull Requests Not Accepted

This repository is maintained solely by the candidate. Pull requests will not be accepted. If you have suggestions, please open an issue instead.
